# 阶段 3：Sa-Token 会话验收记录

## 已验证的行为

使用真实验证码、登录接口、Redis 中的令牌状态和系统业务接口完成 54 项应用级检查，全部通过。覆盖未登录与伪造令牌的 401、最多三个并发令牌及第四个替换最旧令牌、单令牌退出、成员与全局账号停用后的强制下线、停用账号登录拒绝、恢复后重新登录，以及令牌到期后的 401。完整记录见[动态验收明细](阶段3-SaToken动态验收明细.json)。在岗位租户 SQL 拦截器接入后，该矩阵再次执行，仍为 54/54。

静态核对确认，系统管理接口统一受 `/system/**` 登录拦截保护，除认证与健康相关路径外，业务入口使用项目的功能权限注解。业务模块和 `whim-mybatisplus` 不导入 Sa-Token API；会话状态经 `whim-core` 的抽象访问。

## 记住我契约与验收

`rememberMe=true` 按 `sa-token.timeout` 使用当前 7 天的绝对有效期；`false` 或未传时最多按 `sa-token.non-remembered-timeout` 使用当前 1 天。两者都受当前 1 天无活动超时限制。`expiresIn` 返回此次令牌的绝对剩余秒数。前后端分离客户端应分别存入 `localStorage` 或 `sessionStorage`；服务端仅从请求头读取令牌，不能用持久 Cookie 代替客户端存储选择。对两种登录分别核对令牌有效期、不同令牌以及实际受保护接口，**9/9 通过**，见[记住我动态验收明细](阶段3-记住我动态验收明细.json)。登录接口的参数与时效说明已同步到 Apifox。

另以独立租户模拟自然到期，不通过管理接口踢人：到期前令牌可读本租户岗位；直接将 `expire_time` 改为过去后，同一令牌读取岗位与 `userInfo` 均返回 HTTP 403。**6/6** 项通过，见[租户到期动态验收明细](阶段3-租户到期动态验收明细.json)。套餐、角色权限和事务回滚后的会话处理已在[阶段 1 动态验收](阶段1-RBAC动态验收报告.md)的 83 项场景中核对；成员主部门变化与租户上下文另有[阶段 2 动态验收](阶段2-组织归属与数据范围规则.md)。临时数据已清理。

当前系统账号场景下，认证抽象、功能权限、会话失效、令牌长短期和跨租户上下文已达到阶段 3 的完成判定。未来新增账号体系时，仍需为新增场景单独验收。
